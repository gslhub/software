# Changelog — @gslhub/metrics-core

All notable changes to the package are documented here.

## 0.1.0 — 2026-08-18

Initial public-review baseline.

### Added

- framework-independent AIR v0.1.0 calculation;
- framework-independent CR v0.1.0 calculation;
- framework-independent MCP v0.1.0 calculation;
- framework-independent RCR v0.1.0 calculation;
- normalized target type and common URL/domain handling;
- explicit candidate exclusion reporting;
- duplicate-execution protection;
- SHA-256 checksums for normalized inputs and metric outputs;
- auditable query snapshots;
- TypeScript declarations and ESM package output;
- synthetic validation tests aligned with `gslhub/benchmarks`.

### Methodological compatibility

Implements the `0.1.0` metric specifications maintained in `gslhub/benchmarks`.

The synthetic test values are software-validation fixtures and are not empirical research findings.
